**Design:**
- **Declared rule:** `merge: 'commutes'` and `intent: { kind: 'max', field: 'severity', order: SEVERITIES }`, which matches the `sector.report` entry (`max`) in `intents.json`.
- **State:** it holds every report per sector, keyed by op id. Duplicates collapse, so `apply` is idempotent and doesn't mutate its input.
- **Shown severity:** `severityOf` returns the highest severity among reports that no other report covers (the causal frontier).
- **Never reported:** a sector shows `none`.
- **No clock or randomness:** the op file uses neither. `reportPayload` is just `{ severity }`, with no value read from state, so it can't overwrite a concurrent report.

**Requirements:**
- **R2.2:** concurrent reports show the more severe one.
- **R2.3:** a report that has seen the earlier ones can lower the severity. A lowering report doesn't hide a concurrent severe report it hadn't seen.
- **R2.1 and R2.4:** these are covered by the reports being stored per sector and by the convergence and replay properties.
