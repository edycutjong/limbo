## A. Revision: fix the agent permissions schema
`.kiro/agents/limbo-builder.json` and `.kiro/agents/limbo-kitsmith.json` use `{ "tool", "pattern", "action" }` rules. The Kiro CLI v3
schema is `{ "capability": "shell" | "fs_write" | ..., "match": ["glob", ...], "effect": "allow" | "ask" | "deny" }` (one rule may hold
several globs in `match`). Rewrite both files' `permissions.rules` in that schema, keeping the same allow/deny sets.

## B. Eight hooks
Write one standalone hook file per hook in `.kiro/hooks/` and one Node ESM script per hook in `kit/hooks/`. Hook file shape (exactly one
hook per file; `timeout` is in seconds):
```json
{ "version": "v1",
  "hooks": [ { "name": "stop-gate", "description": "...", "trigger": "Stop", "timeout": 120,
               "action": { "type": "command", "command": "node kit/hooks/stop-gate.mjs" } } ] }
```
Add `"matcher": "<value>"` beside `trigger` where the table gives one.

## Shared library `kit/hooks/lib.mjs`
- `readEvent()`: parse the JSON event from STDIN (keys seen from Kiro: `session_id`, `hook_event_name`, `cwd`, plus `tool_name`,
  `tool_input`, `tool_response`, `file_path`, `spec_name`, `task_name`, `task_success` depending on the trigger). Recorded real samples
  are in `kit/hooks/tests/samples/<Trigger>.json` (PostFileSave has the same shape as PostFileCreate).
- `root()`: the repository root = `process.env.LIMBO_ROOT` if set, else two directories above the script (`import.meta.url`). Never the
  process cwd alone.
- `log(row)`: append ONE JSON line to `process.env.LIMBO_HOOKS_LOG` if set, else `<root>/evidence/kiro/hooks.jsonl`. Row:
  `{ts, hook, trigger, target, result, ms, session_id, task, detail}`; `session_id` from the event or `process.env.KIRO_SESSION_ID`;
  `ts` is an ISO log timestamp (never an ordering input). Every script logs exactly one line per invocation, even on error (`result:
  "error"`, and the script still exits 0 except where the table says exit 1/2).
- Running properties (`runFastProps()`): if `<root>/kit/props/run.ts` does not exist, or no `*.op.ts` file exists under `skeleton/src`
  or `apps/*/src`, return `{status: "skipped:no-harness"}` (bootstrap: the kit must never block the session that builds the harness).
  Otherwise run `pnpm exec vitest run --project props` in `<root>` with env `LIMBO_PROPS_TIER=fast`, capture output, and return
  `{status: "pass"|"fail", detail, output}`. Time-box it to 100 s; a timeout is `fail` with detail `timeout`.

## Selftests `kit/hooks/tests/hooks.test.ts` (Vitest)
Spawn each script with `node`, feed it a recorded sample (adjusted per case), and set `LIMBO_HOOKS_LOG` to a temp file and `LIMBO_ROOT`
to a temp fixture directory, so the real ledger is never touched. Cover at least: guard denies `git push origin main`, `git commit -m x`,
`pnpm publish`, `echo ok && git push`, `curl -X POST https://x`; guard allows `pnpm test`, `git status`, `node kit/x.mjs`; op-lint fails
an op using `Date.now()` and one with no `intent`, and one whose intent kind differs from a fixture `intents.json`, and passes a clean
op; op-scaffold creates `<name>.props.test.ts` and `registry.gen.ts` in a fixture `ops/` dir and does not overwrite an existing props
file; stop-gate and props-after-task log `skipped:no-harness` in an empty fixture and print nothing; every script writes exactly one
log line; stop-gate prints a valid `{"decision":"block",...}` JSON when `runFastProps` fails (make the props command overridable with
`LIMBO_PROPS_CMD` so the test can use a command that fails, e.g. `node -e "console.log('counterexample: x');process.exit(1)"`).
Run `pnpm test` and make it pass.
