# AFTERSHOCK

A field form whose sector reports merge into a shared grid, built on the same LIMBO skeleton.

**Demonstration data shape only.** Every sector, count and note is made-up demo data. No field use is claimed.
Convergence is measured, property-tested. It is not proven.

Built from the `aftershock` Kiro spec.

```
pnpm --filter @limbo/aftershock dev        # http://localhost:5176
pnpm --filter @limbo/aftershock build
```
